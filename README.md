# MotionAI
Intelligent Motion Detection System

Making motion detection simple, accessible, and real-time.

MotionAI is a browser-based motion detection project that uses your device's camera and JavaScript to detect movement in real time.

The project analyzes changes between video frames and identifies motion directly in the browser.

---

> Features

- 📷 Live Camera Access — Access your device camera through the browser.
- 🎯 Real-Time Motion Detection — Detect movement by comparing video frames.
- ⚙️ Adjustable Sensitivity — Control how sensitive the motion detection system is.
- 🔢 Motion Event Counter — Keep track of detected motion events.
- 📱 Responsive Interface — Designed to work on mobile devices and desktops.
- 🌐 Browser-Based — No separate application installation required.

---

> How It Works

1. MotionAI requests permission to access the device camera.
2. The camera captures live video.
3. JavaScript analyzes consecutive video frames.
4. The system compares pixel changes between frames.
5. When movement exceeds the selected threshold, motion is detected.
6. The dashboard updates the motion status and event counter.

---

> Getting Started

1. Open the MotionAI project in a modern browser.
2. Allow camera permission.
3. Press Start Camera.
4. Move an object in front of the camera.
5. Observe the motion detection results.

Note: Camera access generally requires HTTPS or localhost.
